## Catalogue complet

La page Registre lit directement `registry/sources/free-for-dev/normalized.json` pour parcourir le catalogue complet importé des candidats `free-for-dev`.

## État des données

Les entrées conservent la catégorie source, l’état du niveau gratuit, l’état de revue, les références brutes aux lignes source et les champs de localisation. `needs_review` signifie que l’entrée nécessite encore une revue humaine.
